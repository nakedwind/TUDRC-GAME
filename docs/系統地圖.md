# 系統地圖

這份文件寫的是：遊戲裡每個功能在哪些檔案、資料存在哪裡、用哪個編輯器改。
要改某個功能之前先查這裡，就知道會動到哪些地方、哪個編輯器要一起改。

- 整理日期：2026-11-10（之後新增或搬動功能時，請順手更新這份文件）
- 看不懂的檔名，打開那個檔案的最上面幾行，通常都有白話說明。

## 先看這裡：整體怎麼運作

| 東西 | 放在哪裡 | 說明 |
|---|---|---|
| 遊戲本體 | `塔防原型.html` | 打開這個就是遊戲。它照順序載入下面所有的 js 檔，**順序很重要**，後面的檔案會用到前面的東西 |
| 遊戲程式 | `js/` | 約 200 個檔案，一個檔案大多管一件事 |
| 遊戲資料 | `data/` | 數值、地圖、台詞、文字。大部分由編輯器存出來，**不要和編輯器同時手改同一個檔** |
| 畫面樣式 | `css/` | 主要是 `css/style.css`，T-Pad 隊員頁另有 `css/squad-page.css` |
| 編輯器 | 根目錄其他的 `.html` | 共 20 個，每個編輯器改一份或幾份 `data/` 裡的檔案 |
| 工具 | `tools/`、`素材搬家.bat` | 本機伺服器、素材搬家、產生資料用的小程式；`tools/draw-mini-snacks.py` 產生劇情用的小零食圖（20×20 以內，放在 `images/道具/小圖/`） |
| 備份 | `backups/` | 大改之前的舊版檔案，遊戲不會讀 |

**三個一定要記得的規則**（詳細在 `CLAUDE.md`）

1. 改了 js 或 css，要更新**每個**載入它的 HTML 裡的 `?v=` 版本號，不然瀏覽器會用舊檔。
2. 同一個數值只放一份（通常在 `data/`），遊戲和編輯器都讀那一份。
3. 遊戲進度存在玩家瀏覽器（localStorage）。新增存檔欄位時，要加進 `js/new-game.js` 的 `progressKeys` 清單，開新遊戲、測試模式、存檔欄位才會一起處理。

所有編輯器共用的程式：

- `js/project-save.js`：一鍵「💾 存到專案」
- `js/draft-sync.js`：瀏覽器暫存和專案檔合併，兩個人一起改才不會蓋掉對方
- `js/editor-nav.js`：最上方的編輯器入口列，新增編輯器要加在這裡
- `js/asset-finder.js`：找新素材
- `js/asset-moves.js`：素材搬家後換掉暫存裡的舊路徑（對照表 `data/asset-moves.js`，由 `素材搬家.bat` 自動產生）
- `js/chair-editor-store.js`：椅子編輯器讀地圖、基地編輯器的素材暫存
- `js/map-picker.js`：選地圖的小視窗
- `js/preview-mute.js`：編輯器預覽遊戲的聲音開關

## 修改時常見的「連動」

改了左邊這件事，記得右邊也要顧到：

| 改了什麼 | 也要顧到 |
|---|---|
| 新增一種裝備 | `data/equipment.js`（或在開發工坊編輯器新增）；溫特身上的實際效果要在 `js/equipment.js` 寫程式；隊員的效果看 `GEAR_SQUAD_MODS` |
| 新增一種存檔資料 | `js/new-game.js` 的 `progressKeys` |
| 新增一個 HUD 元素 | `js/ui-layout.js` 的 `UI_ELEMENTS`（UI編輯器才調得到） |
| 新增一個資訊畫面 | 加進 `js/tpad.js` 的 `TPAD_APPS`，不要再加左上角按鈕 |
| 新增一個電腦小遊戲 | `js/pc-desktop.js` 的 `PCD_APPS` |
| 電腦「音樂播放器」加新的基地音樂 | 音樂檔放進 `music/基地音樂/`，再把檔名加進 `js/pc-desktop.js` 的 `PCD_TRACK_FALLBACK`（直接打開 HTML 或網路版讀不到資料夾，靠這份清單） |
| 新增一個編輯器 | `js/editor-nav.js` 的 `EDITORS`；暫存要用 `DraftSync.load` |
| 素材換資料夾 | 先 commit，再用 `素材搬家.bat` |
| 改某個 js 或 css | 每個載入它的 HTML 都要更新 `?v=` 版本號 |
