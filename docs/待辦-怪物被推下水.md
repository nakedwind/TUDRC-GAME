# 待辦：怪物被推下水

> 給接手的 Claude：這份是交接筆記。動手前請先讀專案根目錄的 `CLAUDE.md`（一律繁體中文、改 js 要更新 `?v=` 版本號、改功能要更新 `docs/系統地圖.md`、不要自己 commit／push、預覽測試要靜音），再查 `docs/系統地圖.md` 裡「不小心掉進深水」「大型怪物落水、水滿溢出來」這兩列。

## 想做什麼

池核（04. 池核，地圖 id `map_mv1bzur4`）和 W118 地下水池這類有 🛟 深水區的地圖上，**地面怪物被推到水邊時，會掉進水裡**，不要再停在水邊。

會把怪物推動的情況（現在都會停在深水邊）：
- 小丑魚 BOSS 落水溢出來的水浪（`js/pool-surge.js` 的 `poolSurgePush`，怪物那一支設定 `e.knockT`、`e.knockVX/VY`）
- 溫特、隊員的攻擊把怪物擊退（`js/combat-feel.js` 約 215 行：`e.knockT = .12; e.knockVX = …`）
- 其他設定 `knockT` 的地方（炸彈、技能……可以搜尋 `knockVX`）

## 現在的程式怎麼運作（已經查過）

- **怪物被擊退的滑行**：`js/combat-feel.js` 的 `updateEnemyFeel` 裡 `if (e.knockT > 0) { … displaceEnemy(e, e.knockVX, e.knockVY, 距離, false) }`
- **`displaceEnemy`**（`js/enemy-ai.js` 約 288 行）：每 4 點走一步，每一步問 `enemyBlocked(nx, ny, e)`，被擋住就試只走 x、只走 y，都不行就停。
- **深水擋怪物**：`enemyBlocked`（`js/enemy-ai.js` 約 231 行）—— 深水格對地面怪物是牆；會飛的人面蝶（`behavior === 'moth'`）不擋；怪物腳下本來就是深水的也不擋。
- **深水的判斷**：`js/swim-ring.js` 的 `deepWaterCells()`、`isDeepWaterCell(c, r)`、`deepWaterAtPoint(x, y)`（會照「碰撞微調」移過的位置算；水被抽乾時一般深水格暫時不算）。
- **本來就住在水裡的怪物**：池核 BOSS（`e.poolBoss`）、比基尼小丑魚、小丑魚幼體（`js/clownfish.js`）—— 這些不該「掉進水裡」。

## 溫特、隊員已經做好的版本（可以參考同一個做法）

- `js/pool-fall.js` 的 `poolFallKnockIn(a, ux, uy, nx, ny)`：滑行被擋住時，如果擋住的是深水，就直接進入「掉下去」→ 落水水花 → 在水裡掙扎。
- 呼叫的地方：`js/bird-head.js` 的 `stepActorKnock`（溫特、隊員共用的滑行），在「被擋住」那一步先問 `poolFallKnockIn`。
- 落水水花：`js/pool-fall.js` 的 `poolCrownSplash(list, x, y, 放大倍數)`，大型怪物可以放大用（BOSS 跳水用 2.6～3.9 倍，見 `js/pool-boss.js` 的 `POOL_BOSS_CROWN`）。水花資料放在 `G.poolSplash`。

## 要做的事

1. 在怪物的滑行（`displaceEnemy` 被擋住的那一步，或 `updateEnemyFeel` 的擊退）判斷：被擋住的是不是深水、這隻怪物會不會掉。
   - 不會掉的：會飛的（`behavior === 'moth'`、`e.airborne`）、本來就在水裡的（BOSS、小丑魚類）、推不動的（`e.unpushable`）、已經在水裡的。
2. 掉下去的表演：往被推的方向掉進水裡一小段（可以參考 `poolFallKnockIn` 找落水點的方法）＋ `poolCrownSplash` 水花（照怪物體型放大）＋ 落水聲（音效 `poolBossSplash` 或另外挑）。
3. **掉下去之後怎樣（要先問使用者決定）**，可能的做法：
   - (a) 直接溺死、算擊殺（給不給獎勵、掉不掉落物？）
   - (b) 在水裡掙扎幾秒、持續扣血，掙扎時間內爬回岸上就活下來
   - (c) 依怪物種類不同（大型怪物爬回岸上、小怪溺死）
4. 怪物泡在水裡的樣子：`js/water.js` 的 `wadeInfo`／`drawWaded` 可以把水面以下畫成半透明（人物溺水、BOSS 潛水都用這套）。
5. 隊員不要一直瞄準已經溺死、正在消失的怪物；怪物在水裡時尋路要停（不然會一直想走回原路）。

## 動手時要注意

- 數值集中放在一個設定物件（例如 `POOL_MONSTER_FALL = { … }`），每個數字旁邊用白話繁體中文寫註解。
- 如果數值要讓企劃在編輯器調（例如怪物編輯器），要問使用者「是否要連 怪物編輯器 也一起同步？」，同一個數值只能有一份來源。
- 改了 `js/enemy-ai.js`、`js/combat-feel.js`、`js/pool-fall.js` 等檔案，記得更新每一個載入它的 HTML 的 `?v=` 版本號（用 `grep -rn "檔名.js?v=" --include=*.html .` 找）。
- 完成後在 `docs/系統地圖.md` 補上這個功能在哪些檔案。

## 怎麼測（預覽裡）

1. 開 `塔防原型.html` → 按「🧪 測試模式」→ 在 console 執行 `Howler.mute(true); switchMap(2);`（第 2 張是 04. 池核）。
2. 地圖很暗看不清楚時，可以在 console 暫時 `window.drawDarkness = function(){}`（只影響這次預覽）。
3. 找一格緊貼深水的岸邊：
   ```js
   const deep = deepWaterCells(); let spot = null;
   for (const k of deep) { const [c, r] = k.split(',').map(Number); if (deep.has(c + ',' + (r - 1)) || isWall(c, r - 1)) continue; spot = center(c, r - 1); break; }
   ```
4. 在那裡放一隻地面怪物（`createMonster(ACTIVE_MONSTERS.find(m => m.id === 'bird_head'), x, y)` 後 `G.enemies.push(...)`），用擊退把牠往水裡推（設 `knockT`、`knockVX/VY`），確認會掉進水裡、有水花、之後的處理照使用者決定的方式。
5. 也測：往牆推照舊停下、會飛的怪物不受影響、小丑魚 BOSS 的水浪（`poolSurgeStart(x, y, 'dive')`）把岸上的怪物往水裡推時的情況（水浪是往遠離水池的方向推，通常不會推進水裡）。
