# 花蓮版權老鼠 RPG 素材

來源為使用者提供的「花蓮版權老鼠」資料夾。8 張使用中的獨立 PNG（hole03 已不使用） 原像素、透明度與 110×90 共用畫布完整保留，只整理英文檔名；中文對照在 source-map.json。未使用 AI 重繪或重新壓縮圖片。

- 本體出土：以 hole-appear（地洞剛出現）開場；mouse-open／half／closed 與洞口分開，Canvas 遮罩及連續垂直位移完成出土。
- 待機眨眼：mouse-open → mouse-half → mouse-closed → mouse-half（不含土堆），hole.png 土堆整張常駐疊在老鼠前方。
- 本體入土：同一遮罩反向收回，洞口保持原地。
- 左手攻擊：left-hand 原圖從 left-hole 遮罩升起，命中時輕微伸展，再平滑縮回；右手由左手組（left-hand＋left-hole）以落點為軸鏡像繪製。
- 死亡：本體收回後留下 hole02（大洞），存在 60 秒、最後 2 秒淡出；不擋路，但溫特、隊員、地面怪物踩在上面移動速度 ×0.2（經 js/build.js 的 slowFactorAt）。

所有圖以同一個畫布位置對齊，請勿逐張裁掉透明邊緣，否則動畫會跳動。遊戲以腳底中央為基準，貼圖底部位於世界 y+13；原圖地洞邊緣約在畫布 y=74。保持 nearest-neighbor／pixelated 縮放。

怪物 ID 是 burrowing_mouse，behavior 是 burrow。數值與 art 映射經怪物編輯器匯出到 data/monsters.js。可在怪物編輯器調整出土時間、預警時間、手部速度、命中半徑、間隔，以及一般 HP／傷害。再於地圖編輯器的怪物種類／權重選用；本次不更改既有地圖的怪物配置。

機制：地底手先鎖定落點並顯示橘圈，預警後才命中一次；玩家離開該落點即可閃避。手與本體分開深度排序，暈眩／睡眠可取消蓄力中的手，死亡後縮回地洞。本體入土後瞬間移到目標附近的可用地板，不逐格移動，也不落在牆壁、障礙物或空洞。目標在本體左側使用左手、右側使用右手；出手與命中保留 5×5 格的尺寸，使用以本體實際座標為中心的 200×200 像素範圍。本體躲回去後原地洞保留 5 秒；死亡後改留 hole02 減速洞（見上）。洞口座標與本體分開記錄，不會隨瞬移移動；手的洞隨招式結束消失。所有計時依遊戲時間，暫停時停止。

怪物編輯器的「單隻測試場」可直接用目前設定實際移動、射擊與閃避。測試場會隔離原有的測試生怪，不改正式地圖，也不寫入正式遊戲進度；可按 P 暫停查看動作。重新挑戰會重新放入同一隻怪物。

編輯器工具列維持「新增異質體／複製」，老鼠已直接列在怪物清單，不再提供專屬新增按鈕。

暫時地圖實測：`BURROW_MOUSE_TEST.enabled` 為 true 時，含老鼠生成權重的戰鬥地圖進場會確保附近亮處有一隻老鼠，優先營地前方、避開牆壁、營地內與佔用格。出現後遊戲直接繼續，不會自動暫停；需要時仍可自行按 P 暫停。無空地會提示走出營地並繼續重試。舊戰場若已沒有老鼠，繼續遊戲時也可補一隻；同一回合不重複補怪。單隻怪物預覽及安全地圖不受影響。測完將此開關改為 false，會恢復純地圖權重隨機生成。

土堆不擋路、也不擋建造（可在土堆上放地雷等炸彈）：入土留下的洞（5 秒）、出土中的本體、手洞、躲在地底的土堆，踩上去移動速度 −80%（溫特、隊員、地面怪物；經 js/build.js 的 slowFactorAt）。此為戰場暫時狀態，不修改地圖或建築資料。

生成與瞬移落點不再對齊格子中心。地圖格網仍提供牆壁、地板及其他怪物的尋路資訊，但老鼠以世界座標連續採樣找落點，檢查完整腳底範圍並避開其他角色。洞口可跨格；建造檢查實際重疊範圍。美術 PNG 原檔未修改，動作由共用 Canvas 函式完成，遊戲、編輯器與死亡收回使用同一套遮罩。

素材清理：已移除 left-hand-rise、right-hand-rise、left-hand-hole、right-hand-hole 四張未使用圖片及映射；hole02.png 依需求保留。

素材精簡：已刪除含土堆的 mouse-hole-open／half／closed（改用無土堆身體＋hole 疊前方）、mouse-emerge（出土由遮罩完成）、right-hand、right-hole（左手鏡像）。舊草稿的 art 映射只會讀取現行鍵，不會再載入已刪檔案。

## 地底循環（2026-10-23）

潛伏 → 鑽地移動 → 出土 → 伸手攻擊 → 入土 → 再鑽向下一個位置（取代原本的瞬間傳送）。

- 潛伏／鑽地時只顯示 hole 土堆；本體移出 G.enemies、放在 G.burrowLurkers：子彈、近戰、隊員索敵都打不到，也不擋路。
- 鑽地以「地底鑽行速度」（怪物編輯器，預設 1.75 格／秒）直線前進，可穿過牆底；地板上沿路冒煙塵、留下 1.6 秒淡出的裂痕（同絲瓜藤）。入土後一定換到離舊洞 1.5 格以外的位置再出土。
- 油桶、油箱、爐具（js/oil-barrels.js）與地雷（js/landmine.js）的爆炸範圍內若有地底老鼠：受爆炸傷害、強制出土並暈眩 6 秒（震暈範圍為爆炸半徑 ×2、至少多 3 格，外圈不受傷）。
- 地底的老鼠仍算在場上怪物數（勝利、完全控制、核心生怪上限）。
- 手的土堆 left-hole 與本體一樣整張蓋在手前方（往下 2 像素）。地底手命中半徑預設 1.2 格。
- 音效（Sound effects/怪物/老鼠）：mouseDig 鑽土（入土、地底移動每 1.8 秒）、mouseOut 鑽出、mouseAttack 手鑽出地面、mouseHurt 被打、mouseDeath 死掉（暫用被打音效播低 0.8）。
- 暈眩（任何來源的 stunT）：mouse-dizzy01～04 每 0.22 秒隨機換一張，頭上三顆星星繞圈，本體以洞口為軸左右搖 ±0.045 弧度（底部不動，不會露出土堆外）。
- 死掉音效 mouseDeath：老鼠被打放大（音量倍率 1.8，在音效編輯器可調）、播放速度 0.72 壓低，加回音（js/sfx.js 的 SOUND_ECHO）。
