# 台北地下災害應變中心（暫名）

一款開發中的 **HTML 網頁遊戲**。玩家扮演「嚮導」，坐鎮台北地下災害應變中心，
佈署擁有特殊能力的「哨兵」抵禦從後室湧出的怪物——同時得在哨兵精神汙染值爆表、
**暴走**反咬之前，及時**疏導**他們。

> 與前作《苦艾與甘露》為同一宇宙。

## 類型
經營 ＋ 養成 ＋ 塔防戰鬥。

## 回憶劇情與 🎬 劇情編輯器

- 遊戲裡從「記憶之門」進入回憶（見下面）；開發時可以用 🎬 劇情編輯器的「▶ 預覽」，或劇情地圖編輯器預覽這張地圖的草稿。
- 用「🎬 劇情編輯器」（`劇情編輯器.html`）編輯：站位、群演（開槍的哨兵、揮擊的生命體、走動的嚮導、躺床的傷員）、鏡頭、地點、遠處偶爾的爆炸聲、BGM（音樂檔放在 `music/`），以及每一頁的台詞與演出（鏡頭、走位、轉向、睜眼閉眼、治療、槍聲變稀疏）。在地圖上拖曳就能移動，左邊的「檢查」會列出找不到的人或站在牆裡的位置。
- 編輯器的「▶ 從頭預覽」與每頁的「▶ 從這頁預覽」直接用還沒存檔的草稿；「💾 存到專案」寫進 `data/story-scenes.js`。
- 一個檔案可以放好幾段劇情；每段有自己的 id，用 `map` 指定在哪張劇情地圖演出。遊戲網址：`?storyPreview=劇情id`（`&storyDraft=1` 用草稿、`&storyFrom=N` 從第 N 頁開始）。
- 對話使用遊戲內的正式對話框（說話者頭像在編輯器的「🖼️ 頭像」設定，旁白不放頭像）。Space、Enter 或點擊畫面推進對話；文字還在出現時，第一次操作會顯示全文。結束後可重播或返回開始畫面。
- **記憶之門**：地圖編輯器選一扇門，種類選「記憶之門」，旁邊再選 🔑 回憶鑰匙和 🎬 劇情。遊戲裡帶著那把鑰匙按 Space，門上的鎖鏈圖會碎掉、門打開（鑰匙不會用掉，解開過的門記在存檔）；之後按 Space 選「進入」就直接播那段回憶，看完回到門前（`js/memory-doors.js`）。
- **T-Pad「回憶」App**：列出每個人的回憶（9 把回憶鑰匙），還沒解鎖的只顯示是誰的回憶、碎片進度、鑰匙拼好了沒、門在哪張地圖；解開過記憶之門的回憶可以按「▶ 播放這段回憶」重看，看完回到原本的位置（`js/tpad-memories.js`）。
- 播放器在 `js/story-scene.js`；群演只有動作與特效、不會造成傷害；走動的人會自己繞過地圖的不可穿透格。
- 預覽不寫入正式進度。瀏覽器流程驗證：`node tools/test-story-scene.cjs`（需 Playwright，亦支援 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH`）。
