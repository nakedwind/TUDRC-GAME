# 台北地下災害應變中心（暫名）

一款開發中的 **HTML 網頁遊戲**。玩家扮演「嚮導」，坐鎮台北地下災害應變中心，
佈署擁有特殊能力的「哨兵」抵禦從後室湧出的怪物——同時得在哨兵精神汙染值爆表、
**暴走**反咬之前，及時**疏導**他們。

> 與前作《苦艾與甘露》為同一宇宙。

## 類型
經營 ＋ 養成 ＋ 塔防戰鬥。

## 檔案導覽
| 檔案 | 內容 |
|------|------|
| [`塔防原型.html`](塔防原型.html) | 可玩的塔防原型（單一檔案，**雙擊即可用瀏覽器開啟**） |
| [`物件編輯器.html`](物件編輯器.html) | 設定障礙物圖片格數與實際擋路範圍 |
| [`劇情設定.md`](劇情設定.md) | 世界觀、角色、關係、劇情設定 |
| [`玩法設定.md`](玩法設定.md) | 遊戲機制、玩法、原型現況、開發策略 |
| `*_avatar.png` / `character_*.png` | 角色頭像與立繪 |
